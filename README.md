# ❤️ Heart Disease Prediction

An interactive Machine Learning web application built with Python and Flask to predict the likelihood of heart disease based on user-provided health parameters.

## 📌 Project Overview

Heart disease is a major health concern worldwide. This project demonstrates how Machine Learning can analyze health-related input data and generate predictive results through a simple, user-friendly web interface.

The application combines a trained ML model with a web dashboard to demonstrate an end-to-end prediction workflow.

**Note:** This project is for educational purposes only and is not a substitute for professional medical diagnosis.

## ✨ Key Features

- **Heart Disease Prediction:** Generates predictions based on user-provided input parameters.
- **Machine Learning Integration:** Uses a trained model for predictive analysis.
- **Interactive Dashboard:** Provides a user-friendly interface for entering data and viewing results.
- **Flask Web Application:** Connects the prediction model to a web-based interface.
- **Data-Driven Analysis:** Demonstrates the practical application of Machine Learning in healthcare-related data analysis.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Web Framework:** Flask
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Frontend:** HTML, CSS
- **Model Serialization:** Joblib

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd Heart-Disease-Prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

Use the command matching your actual folder structure. For example:

```bash
python app/app.py
```

Open the local URL displayed in your terminal, typically:

`http://127.0.0.1:5000`
